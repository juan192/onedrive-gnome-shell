# OneDrive Client for GNOME Shell 50

Extensión para GNOME Shell 50 / Wayland que permite controlar y monitorizar
el cliente OneDrive para Linux de abraunegg.
Probado en Ubuntu 26.04

## Funciones

- Arrancar y detener OneDrive mediante un interruptor
- Estado:
  - Detenido
  - Sincronizando
  - Sincronizado
- Última sincronización
- Forzar sincronización
- Login / Reautenticar
- Mostrar estado del servicio
- Mostrar logs del servicio
- Abrir OneDrive web
- Abrir carpeta local de OneDrive

## Requisitos

- GNOME Shell 50
- OneDrive Client for Linux:
  https://github.com/abraunegg/onedrive

## Instalación

Copiar la extensión a:

~/.local/share/gnome-shell/extensions/

Cerrar sesión y volver a entrar.
